# Third-party resources

No third-party source code, dataset imagery, labels, model weights, or
prediction rasters are redistributed in this release.

The experiments depend on or compare against the following external resources:

- Massachusetts Roads Dataset, V. Mnih, obtained separately from the original
  dataset page: https://www.cs.toronto.edu/~vmnih/data/
- DeepGlobe Road Extraction Challenge data, obtained separately under the
  distributor's terms.
- SpaceNet APLS reference implementation, obtained separately from the SpaceNet
  repositories and used for the raster-graph audit described in the source.
- Offroad Path Planning / URA* reference project:
  https://github.com/shaswata09/Offroad-Path-Planning

Users are responsible for complying with the licenses and access conditions of
those upstream resources.
