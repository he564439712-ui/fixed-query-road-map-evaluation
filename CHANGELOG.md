# Changelog

## v1.0.0 — 2026-09-10

First archival research-software release for the manuscript *From Road
Extraction to Route Decisions: A Route-Level Evaluation of Imperfect
Remote-Sensing Road Maps*.

- Freezes the Massachusetts and DeepGlobe experiment configuration.
- Includes the segmentation, calibration, topology-repair, route-planning,
  factorial, search-cap, bridge, APLS, and negative rank-audit code paths.
- Includes the numerical CSV and JSON evidence needed to inspect the reported
  tables and principal statistical conclusions.
- Excludes third-party source, source datasets, imagery, labels, model weights,
  prediction rasters, logs, manuscript source, and machine-specific files.
